EXPERIMENT 1 - NETWORK CABLES  (Packet Tracer: Exp01_Network_Cables.pkt)
=====================================================================

----- PART A : REAL CABLE (only if lab gives you cable + crimper) -----
STEP 1  Cut UTP cable, strip 1 inch jacket from both ends.
STEP 2  STRAIGHT cable : both ends T568B
        Pin1 W/Orange | 2 Orange | 3 W/Green | 4 Blue | 5 W/Blue | 6 Green | 7 W/Brown | 8 Brown
STEP 3  CROSS cable    : END-1 T568A , END-2 T568B
        T568A : 1 W/Green | 2 Green | 3 W/Orange | 4 Blue | 5 W/Blue | 6 Orange | 7 W/Brown | 8 Brown
STEP 4  Insert in RJ45 -> crimp -> test with cable tester.


----- PART B : PACKET TRACER -----
Cables: Switch<->PC = straight | PC<->PC = crossover | Router<->Switch = straight | Router<->PC = crossover


=== ROUTER0 (click Router0 -> CLI tab) ===
(if it asks "Would you like to enter the initial configuration dialog?" type: no)

enable
configure terminal
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface GigabitEthernet0/1
ip address 192.168.2.1 255.255.255.0
no shutdown
end
write memory

OUTPUT after "no shutdown":
%LINK-5-CHANGED: Interface GigabitEthernet0/0, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface GigabitEthernet0/0, changed state to up
