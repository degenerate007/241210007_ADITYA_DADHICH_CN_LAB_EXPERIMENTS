EXPERIMENT 9 - ROUTING PROTOCOLS (RIP v2)  (Packet Tracer: Exp09_Routing_Protocols.pkt)
======================================================================================

TOPOLOGY: PC0 -- R1 (Gi0/0) ; R1 (Gi0/1) -- R2 (Gi0/0) ; R2 (Gi0/1) -- R3 (Gi0/0) ; R3 (Gi0/1) -- PC1
Cables: router<->router and router<->PC = crossover.
(for every router CLI: if asked initial configuration dialog -> type: no)


=== STEP 1 : R1 (CLI tab) ===
Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip address 10.0.12.1 255.255.255.252
R1(config-if)# no shutdown
R1(config-if)# end

=== STEP 2 : R2 (CLI tab) ===
Router> enable
Router# configure terminal
Router(config)# hostname R2
R2(config)# interface GigabitEthernet0/0
R2(config-if)# ip address 10.0.12.2 255.255.255.252
R2(config-if)# no shutdown
R2(config-if)# exit
R2(config)# interface GigabitEthernet0/1
R2(config-if)# ip address 10.0.23.1 255.255.255.252
R2(config-if)# no shutdown
R2(config-if)# end

=== STEP 3 : R3 (CLI tab) ===
Router> enable
Router# configure terminal
Router(config)# hostname R3
R3(config)# interface GigabitEthernet0/0
R3(config-if)# ip address 10.0.23.2 255.255.255.252
R3(config-if)# no shutdown
R3(config-if)# exit
R3(config)# interface GigabitEthernet0/1
R3(config-if)# ip address 192.168.3.1 255.255.255.0
R3(config-if)# no shutdown
R3(config-if)# end


=== STEP 4 : PC0 : Desktop > IP Configuration ===
IP Address      : 192.168.1.2
Subnet Mask     : 255.255.255.0
Default Gateway : 192.168.1.1

=== PC1 ===
IP Address      : 192.168.3.2
Subnet Mask     : 255.255.255.0
Default Gateway : 192.168.3.1


=== STEP 5 : BEFORE routing (should FAIL) ===
PC0 Command Prompt:
C:\> ping 192.168.3.2
Reply from 192.168.1.1: Destination host unreachable.   (fails - routers don't know the remote network)


=== STEP 6 : ENABLE RIP v2 ===

R1:
R1# configure terminal
R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# no auto-summary
R1(config-router)# network 192.168.1.0
R1(config-router)# network 10.0.0.0
R1(config-router)# end
R1# write memory

R2:
R2# configure terminal
R2(config)# router rip
R2(config-router)# version 2
R2(config-router)# no auto-summary
R2(config-router)# network 10.0.0.0
R2(config-router)# end
R2# write memory

R3:
R3# configure terminal
R3(config)# router rip
R3(config-router)# version 2
R3(config-router)# no auto-summary
R3(config-router)# network 10.0.0.0
R3(config-router)# network 192.168.3.0
R3(config-router)# end
R3# write memory

WAIT ABOUT 30 SECONDS for routing updates.


=== STEP 7 : VERIFY ON R1 ===

R1# show ip route

=== OPTIONAL : OSPF instead of RIP (remove RIP first: no router rip) ===
R1(config)# router ospf 1
R1(config-router)# network 192.168.1.0 0.0.0.255 area 0
R1(config-router)# network 10.0.12.0 0.0.0.3 area 0
R2(config)# router ospf 1
R2(config-router)# network 10.0.12.0 0.0.0.3 area 0
R2(config-router)# network 10.0.23.0 0.0.0.3 area 0
R3(config)# router ospf 1
R3(config-router)# network 10.0.23.0 0.0.0.3 area 0
R3(config-router)# network 192.168.3.0 0.0.0.255 area 0
R1# show ip route        -> routes marked  O

=== OPTIONAL : STATIC routes instead (remove RIP first) ===
R1(config)# ip route 192.168.3.0 255.255.255.0 10.0.12.2
R1(config)# ip route 10.0.23.0 255.255.255.252 10.0.12.2
R2(config)# ip route 192.168.1.0 255.255.255.0 10.0.12.1
R2(config)# ip route 192.168.3.0 255.255.255.0 10.0.23.2
R3(config)# ip route 192.168.1.0 255.255.255.0 10.0.23.1
R3(config)# ip route 10.0.12.0 255.255.255.252 10.0.23.1

=== OPTIONAL : link failure test ===
R2(config)# interface gig0/1
R2(config-if)# shutdown          -> wait ~3 min, remote routes disappear
R2(config-if)# no shutdown       -> routes come back
