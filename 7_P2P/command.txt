EXPERIMENT 7 - PEER TO PEER (Switch + Router)  (Packet Tracer: Exp07_Peer_to_Peer_Switch_Router.pkt)
===================================================================================================

TOPOLOGY: Router0 Gi0/0 -> Switch0 Fa0/1
          PC0 -> Switch0 Fa0/2
          PC1 -> Switch0 Fa0/3
Cables: all straight-through.


=== ROUTER0 (click Router0 -> CLI tab) ===
(if asked initial configuration dialog -> type: no)

enable
configure terminal
interface gigabitEthernet 0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
end
write memory

OUTPUT:
%LINK-5-CHANGED: Interface GigabitEthernet0/0, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface GigabitEthernet0/0, changed state to up
