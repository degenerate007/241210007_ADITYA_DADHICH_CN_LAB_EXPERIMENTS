EXPERIMENT 10 - TCP / UDP CLIENT-SERVER  (Packet Tracer: Exp10_TCP_UDP_Client_Server.pkt + Python)
==================================================================================================


########## PART A : PACKET TRACER ##########

TOPOLOGY: Server0 (Switch Fa0/1), PC0 (Switch Fa0/2), PC1 (Switch Fa0/3). Straight cables.

=== SERVER0 : Desktop > IP Configuration ===
IP Address      : 192.168.1.10
Subnet Mask     : 255.255.255.0
Default Gateway : (leave empty)

=== PC0 ===
IP Address      : 192.168.1.2
Subnet Mask     : 255.255.255.0

=== PC1 ===
IP Address      : 192.168.1.3
Subnet Mask     : 255.255.255.0
DNS Server      : 192.168.1.10


--- TCP (HTTP) ---
STEP 1  Server0 > Services > HTTP -> make sure HTTP = ON
STEP 2  Click "Simulation" -> Edit Filters -> keep only HTTP and TCP
STEP 3  PC0 > Desktop > Web Browser -> URL: http://192.168.1.10 -> Go
STEP 4  Press Capture/Forward repeatedly. You will see:
        SYN -> SYN-ACK -> ACK -> HTTP request -> HTTP response -> FIN
        Web page "Cisco Packet Tracer" opens in the browser.

--- UDP (DNS) ---
STEP 5  Server0 > Services > DNS -> DNS Service = ON
        Name: www.lab.com    Address: 192.168.1.10    -> click Add
STEP 6  PC0 and PC1 > Desktop > IP Configuration -> DNS Server = 192.168.1.10
STEP 7  Simulation mode, filter = DNS, UDP
STEP 8  PC1 > Command Prompt:

nslookup www.lab.com
Server: [192.168.1.10]
Address: 192.168.1.10

Non-authoritative answer:
Name:    www.lab.com
Address: 192.168.1.10

STEP 9  Capture/Forward -> only 1 UDP query + 1 UDP reply, NO handshake.
STEP 10 Click any PDU -> OSI Model tab -> see TCP/UDP ports (HTTP=80, DNS=53).


########## PART B : PYTHON SOCKETS ##########
(open Command Prompt / Terminal; if "python3" is not found use "python")

STEP 1  Go to the folder:
        cd 10_TCP_UDP_Client_Server

--- TCP ---
TERMINAL 1 (start server FIRST):
python3 tcp_server.py
[TCP Server] Listening on 127.0.0.1:5000

TERMINAL 2:
python3 tcp_client.py
[TCP Client] Connected to 127.0.0.1:5000
[TCP Client] Server replied: ACK: Hello TCP Server

TERMINAL 1 now shows:
[TCP Server] Connected by ('127.0.0.1', 56003)
[TCP Server] Received: Hello TCP Server
[TCP Server] Connection closed

--- UDP ---
TERMINAL 1 (start server FIRST):
python3 udp_server.py
[UDP Server] Waiting for datagram on 127.0.0.1:6000

TERMINAL 2:
python3 udp_client.py
[UDP Client] Datagram sent
[UDP Client] Server replied: ACK: Hello UDP Server

TERMINAL 1 now shows:
[UDP Server] Received 'Hello UDP Server' from ('127.0.0.1', 52736)

(client port numbers 56003 / 52736 differ every run - this is normal)

IF ERROR "Address already in use": wait ~30 sec or close the old server terminal and run again.
