EXPERIMENT 5 - LAN CONNECTION  (Packet Tracer: Exp05_LAN_Connection.pkt)
========================================================================

TOPOLOGY: 1 Switch (2960) + 4 PCs. Straight-through cables.
   PC0 -> Switch Fa0/1
   PC1 -> Switch Fa0/2
   PC2 -> Switch Fa0/3
   PC3 -> Switch Fa0/4
Wait until all link lights turn green (about 30 sec).


=== PC0 : Desktop > IP Configuration (Static) ===
IP Address      : 192.168.10.1
Subnet Mask     : 255.255.255.0
Default Gateway : (leave empty)

=== PC1 ===
IP Address      : 192.168.10.2
Subnet Mask     : 255.255.255.0

=== PC2 ===
IP Address      : 192.168.10.3
Subnet Mask     : 255.255.255.0

=== PC3 ===
IP Address      : 192.168.10.4
Subnet Mask     : 255.255.255.0
