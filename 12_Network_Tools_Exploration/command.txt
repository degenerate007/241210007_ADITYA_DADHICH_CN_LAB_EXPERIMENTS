########## PART A : PACKET TRACER ##########

TOPOLOGY: PC0 (Switch Fa0/1), PC1 (Switch Fa0/2), Router0 Gi0/0 (Switch Fa0/3)
          Router0 Gi0/1 --- Server0 (crossover)

=== ROUTER0 (CLI tab) ===
(if asked initial configuration dialog -> type: no)

enable
configure terminal
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface GigabitEthernet0/1
ip address 172.16.0.1 255.255.255.0
no shutdown
end
write memory

=== PC1 ===

=== SERVER0 ===
IP Address      : 172.16.0.10

=== SIMULATION ===
STEP 1  Click "Simulation" (bottom right). Edit Filters -> keep only ARP and ICMP.
STEP 2  PC0 > Command Prompt:

ping 172.16.0.10
Pinging 172.16.0.10 with 32 bytes of data:
Request timed out.
Reply from 172.16.0.10: bytes=32 time<1ms TTL=127
Reply from 172.16.0.10: bytes=32 time<1ms TTL=127
Reply from 172.16.0.10: bytes=32 time<1ms TTL=127
Ping statistics for 172.16.0.10:
    Packets: Sent = 4, Received = 3, Lost = 1 (25% loss)

STEP 3  Click Capture/Forward repeatedly and note:
        ARP request  -> broadcast FF:FF:FF:FF:FF:FF (asking MAC of 192.168.1.1)
        ARP reply    -> unicast with router MAC
        ICMP echo request (type 8) / echo reply (type 0), TTL decreases at router
STEP 4  Click any packet (envelope) -> Inbound/Outbound PDU Details -> see Ethernet, IP, ICMP fields.


########## PART B : TOOLS (on lab PC / terminal) ##########

--- WIRESHARK ---
STEP 1  Open Wireshark -> double-click your active interface (Wi-Fi / Ethernet) to start capture.
STEP 2  In another Command Prompt:
        ping 192.168.1.1        (or ping 8.8.8.8)
STEP 3  Type these in the Wireshark display filter bar, press Enter, one by one:
        icmp
        arp
        tcp.port == 80
        udp.port == 53
        ip.addr == 192.168.1.1
        tcp.flags.syn == 1
STEP 4  Stop capture (red square). File > Save as -> capture.pcap
