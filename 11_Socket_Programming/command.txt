########## PART B : PYTHON (threaded server) ##########
(if "python3" is not found use "python")

STEP 1  Open 4 terminals. In each one:
        cd 11_Socket_Programming

TERMINAL 1 (server FIRST):
python3 threaded_server.py
[Server] Listening on 127.0.0.1:7000

TERMINAL 2:
python3 client.py Alice "hello network"
[Alice] Welcome Alice! Send text, I will return it in UPPERCASE.
[Alice] Reply: HELLO NETWORK

TERMINAL 3:
python3 client.py Bob "sockets are fun"
[Bob] Welcome Bob! Send text, I will return it in UPPERCASE.
[Bob] Reply: SOCKETS ARE FUN

TERMINAL 4:
python3 client.py Carol "tcp and udp"
[Carol] Welcome Carol! Send text, I will return it in UPPERCASE.
[Carol] Reply: TCP AND UDP

TERMINAL 1 (server) now shows:
[Server] Listening on 127.0.0.1:7000
[Server] Alice connected from port 56004
[Server] Alice says: hello network
[Server] Alice disconnected
[Server] Bob connected from port 56005
[Server] Bob says: sockets are fun
[Server] Bob disconnected
[Server] Carol connected from port 56006
[Server] Carol says: tcp and udp
[Server] Carol disconnected

(port numbers differ every run. Server stops by itself after 3 clients.
 Run clients one after another, server must be running first.)
