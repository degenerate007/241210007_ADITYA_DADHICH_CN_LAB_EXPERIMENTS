EXPERIMENT 6 - ROUTER CONFIGURATION  (Packet Tracer: Exp06_Router_Configuration.pkt)
===================================================================================

TOPOLOGY: PC_00 --- Router2 (Gi0/0) ; Router2 (Gi0/1) --- PC_01
Cable: PC <-> Router = crossover.


=== ROUTER2 (click router -> CLI tab) ===
(if asked initial configuration dialog -> type: no)

enable
configure terminal
hostname Router2
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface GigabitEthernet0/1
ip address 192.168.2.1 255.255.255.0
no shutdown
end
write memory

OUTPUT:
%LINK-5-CHANGED: Interface GigabitEthernet0/0, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface GigabitEthernet0/0, changed state to up
Building configuration...
[OK]

=== OPTIONAL : secure router (only if asked) ===
configure terminal
enable secret cisco123
line console 0
password cisco
login
exit
banner motd #Authorized access only#
service password-encryption
end
write memory

=== OPTIONAL : exercise (shutdown test) ===
configure terminal
interface gig0/1
shutdown
end
show ip route          -> only 192.168.1.0 route remains
ping 192.168.2.2         -> Destination host unreachable
configure terminal
interface gig0/1
no shutdown
