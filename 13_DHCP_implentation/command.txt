EXPERIMENT 13 - DHCP IMPLEMENTATION  (Packet Tracer: 13_DHCP_implentation.pkt)
=============================================================================

TOPOLOGY: Router0 Gi0/0 -> Switch0 Fa0/1
          PC0 -> Switch0 Fa0/2
          PC1 -> Switch0 Fa0/3
Cables: all straight-through.


=== STEP 1 : ROUTER0 (click Router0 -> CLI tab) ===
(if asked initial configuration dialog -> type: no)

enable
configure terminal
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
ip dhcp excluded-address 192.168.1.1 192.168.1.99
ip dhcp pool LAN_POOL
network 192.168.1.0 255.255.255.0
default-router 192.168.1.1
dns-server 8.8.8.8
end
write memory

OUTPUT:
%LINK-5-CHANGED: Interface GigabitEthernet0/0, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface GigabitEthernet0/0, changed state to up
Building configuration...
[OK]


=== STEP 2 : PC0 : Desktop > IP Configuration ===
Select  DHCP   (wait 2-3 sec)
-> "DHCP request successful."

=== STEP 3 : PC1 : Desktop > IP Configuration ===
Select  DHCP


=== STEP 4 : PC0 : Desktop > Command Prompt ===

ipconfig
FastEthernet0 Connection:(default port)
   IPv4 Address....................: 192.168.1.100
   Subnet Mask.....................: 255.255.255.0
   Default Gateway.................: 192.168.1.1
   DNS Server......................: 8.8.8.8

ping 192.168.1.1
Reply from 192.168.1.1: bytes=32 time<1ms TTL=255   (x3 or x4)

ping 192.168.1.101
Reply from 192.168.1.101: bytes=32 time<1ms TTL=128   (x3 or x4)

   Subnet Mask.....................: 255.255.255.0
   Default Gateway.................: 192.168.1.1

=== STEP 6 : ROUTER0 CLI : verify ===

show ip dhcp binding

192.168.1.100    xxxx.xxxx.xxxx                 --                   Automatic
192.168.1.101    xxxx.xxxx.xxxx                 --                   Automatic

(MAC values differ on your system. First PC gets .100 because .1-.99 are excluded)
