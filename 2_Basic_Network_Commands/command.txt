EXPERIMENT 2 - BASIC NETWORK COMMANDS  (Packet Tracer: Exp02_Basic_Network_Commands.pkt)
=======================================================================================

TOPOLOGY: PC0, PC1 --- Switch0 --- Router0 (Gi0/0) ; Router0 (Gi0/1) --- Server0
Cables: PC/Switch/Router-Gi0/0 = straight. Router Gi0/1 <-> Server0 = crossover.


=== ROUTER0 (click Router0 -> CLI tab) ===
(if asked initial configuration dialog -> type: no)

enable
configure terminal
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface GigabitEthernet0/1
ip address 10.0.0.1 255.255.255.0
no shutdown
end
write memory
